# HHHTheRideApp  

HHHTheRideApp is a free FlutterFlow project that was done as a collaboration between myself and two classmates. Due to FlutterFlow's free tier limitations, the project source is not publicly accessible. 

This repo will contain the slide decks for three of the four iterations and the SRS that we created.
